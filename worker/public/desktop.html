37Studio in its own window

The same studio as the Docker version, as a normal app on Windows and Linux: the same brands, projects, agent and publishing, with no Docker to install. It's a preview, so tell us on GitHub what breaks.

Install

  1. Download the Windows .zip above.
  2. Right-click it → Properties → tick Unblock → OK, then unpack it. Windows marks downloaded files and refuses to run what it marked.
  3. In the unpacked folder, right-click install-windows.ps1 → Run with PowerShell. It copies 37Studio to %LOCALAPPDATA%\Programs\37Studio and adds it to the Start menu. No admin rights needed.
  4. Install the tools the agent uses.
  5. Press the Windows key, type 37Studio and open it. Overview → Finish setup lists anything still missing.
"Windows protected your PC"? The app isn't signed yet, so the first start may show this. Click More info → Run anyway. Signing comes with the first release out of preview.

From a terminal instead of right-clicking: powershell -ExecutionPolicy Bypass -File .\install-windows.ps1. You can also run 37studio.exe straight from the unpacked folder; keep its name, because the agent runs 37studio commands from that folder.

Your work is kept in %AppData%\37Studio on Windows and ~/.local/share/37studio on Linux. Links, the timeline editor and social sign-ins open in your browser, and downloads and backups ask where to save.

Desktop or Docker?

Pick the desktop app ifyou're on Windows or Linux, don't want Docker, and are happy to install a few tools yourself. Nothing runs in the background but the app itself.
Pick the Docker version ifyou're on a Mac, run it on a server, or want every tool bundled and set up for you. It's the fully supported way, and it updates itself on each start.

Both keep their data in a different folder. To move your Docker brands and videos into the desktop app, see docs/desktop.md on GitHub.

Updates and removing

  • Updates: Settings → About says when a new version is out. Download it from this page and install it the same way. On Windows, close 37Studio first, then run install-windows.ps1 again.
  • Remove on Windows: .\install-windows.ps1 -Uninstall. Your work in %AppData%\37Studio stays.
  • Remove on Ubuntu or Debian: sudo apt remove 37studio. Your work in ~/.local/share/37studio stays.

Troubleshooting

The agent stops on its first step on Windows

Git for Windows is missing. Install it with winget install Git.Git, then close 37Studio and open it again.

Something is missing

Overview → Finish setup lists each missing tool with the command to install it. After installing, press Check again. On Windows, open 37Studio again so it sees the new PATH.

Ubuntu: the window doesn't open from the app menu

Ubuntu only lets programs with an AppArmor profile use the sandbox the window is drawn in. The .deb from 0.9.1 on adds the profile itself. With 0.9.0 or the .tar.gz, add it once in a terminal (change the path if you unpacked the .tar.gz somewhere else):

app=/usr/lib/37studio/37studio
printf 'abi <abi/4.0>,\ninclude <tunables/global>\nprofile 37studio %s flags=(unconfined) {\n  userns,\n}\n' "$(realpath "$app")" | sudo tee /etc/apparmor.d/37studio
sudo apparmor_parser -r /etc/apparmor.d/37studio

The program doesn't open on Linux

Run ./37studio from a terminal to see why. Usually GTK 4 or WebKitGTK 6.0 is missing: install gtk4 and webkitgtk6.0 (Fedora) or libgtk-4-1 and libwebkitgtk-6.0-4 (Ubuntu, Debian).

Stuck? Open an issue on GitHub, or read the full desktop guide, which also covers building the app yourself.
