Donate with bKash

  1. In the bKash app, choose Send Money.
  2. Send any amount to 01635191148
  3. Write 37Studio as the reference.
  4. Tell us below, with the transaction ID (TrxID) from the bKash message, so we can count it and thank you.

We check every report against our bKash account by hand before it counts, usually within a day. Only confirmed donations appear on this page.

From outside Bangladesh

We can't take international cards on this page yet. If you'd like to support us from abroad, email jahangir@shaitrish.com and we'll sort out a way that works for you.

Other ways to help

  • Star it on GitHub, so more people find it.
  • Report bugs and suggest features in Issues.
  • Send a pull request: see CONTRIBUTING.md.
  • Share a video you made with it, and tag us.
  • Want it set up for you? We do paid setup over a screen share: message us on WhatsApp.
